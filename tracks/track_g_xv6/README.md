# Track G — xv6 OS optimization (not implemented)

This folder intentionally does not claim an xv6 kernel modification. To complete:
1. Clone the course-prescribed xv6 repository.
2. Select one kernel feature (e.g. lottery scheduler or syscall exposing scheduling stats).
3. Preserve the original commit and record a patch/diff.
4. Build and boot under QEMU after each change.
5. Run `usertests` and at least three repeatable workloads.
6. Report baseline vs modified response time/turnaround/throughput/fairness.
7. Commit the actual patch and include QEMU logs.

Do not submit this checklist as proof of implementation.
